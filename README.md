# E-Commerce Web Application

A full-stack e-commerce web application built with ASP.NET Core MVC, Entity Framework Core, and SQL Server. Designed with a clean architecture and a modern UI to deliver a seamless online shopping experience.

---

## Key Features

* **User Authentication & Role Management:** Secure registration, login, and user role handling.
* **Product Catalog & Management:** Browse items, view detailed product pages, and manage inventory.
* **Shopping Cart & Checkout:** Add/remove items dynamically and track order placement.
* **Real-time Inventory Tracking:** Keep stock levels accurate and updated dynamically.

---

## Tech Stack

* **Backend:** C#, ASP.NET Core MVC, LINQ, Entity Framework Core
* **Database:** Microsoft SQL Server
* **Frontend:** Razor Views (`.cshtml`), HTML5, CSS3, Tailwind CSS, JavaScript
